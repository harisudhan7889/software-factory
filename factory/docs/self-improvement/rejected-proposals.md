# Rejected Proposals

Factory Improvement Proposals (classification #4 from `../../../skills/
self-improvement/references/standard.md`) that were presented to the
user and explicitly declined. An approved proposal does not get an
entry here — the applied skill/policy diff and its commit are already
the record.

Read this file before proposing a factory change, so a previously
rejected idea isn't silently re-proposed. If a new run's context
substantially changes the reasoning (new evidence, changed scope),
surface the prior rejection and its rationale to the user and confirm
they still want to proceed before re-proposing it.

This file replaces the `rfc` skill's former one-off
`/memories/rfc/rejected-*.md` convention — a rejected RFC proposal is
recorded here like any other rejected factory improvement.

Each entry carries a `Status`; update it to `superseded` (with the
accepted replacement) rather than deleting the entry.

Statuses: `rejected` · `superseded`.
